PYTHON RECURSION - 30 PRACTICE QUESTIONS

LEVEL 1: BEGINNER (1-10) Focus: Basic recursion, numbers, strings, and
lists.

1.  Write a recursive function to print numbers from 1 to 10.
2.  Write a recursive function to print numbers from 10 to 1.
3.  Write a recursive function to find the sum of numbers from 1 to N.
4.  Write a recursive function to find the factorial of a number.
5.  Write a recursive function to find the sum of all elements in a
    list.
6.  Write a recursive function to find the length of a list without
    using len().
7.  Write a recursive function to print each character of a string
    separately.
8.  Write a recursive function to reverse a string.
9.  Write a recursive function to calculate the power of a number.
    Example: 2^3 = 8.
10. Write a recursive function to find the sum of digits of a number.
    Example: 1234 = 10.

LEVEL 2: INTERMEDIATE (11-20) Focus: Slicing, multiple parameters,
lists, conditions, and mathematical logic.

11. Write a recursive function to find the largest element in a list.
12. Write a recursive function to find the smallest element in a list.
13. Write a recursive function to count the number of even elements in a
    list.
14. Write a recursive function to count the number of odd elements in a
    list.
15. Write a recursive function to check whether a given string is a
    palindrome.
16. Write a recursive function to print all prefixes of a string.
    Example: python -> p, py, pyt, pyth, pytho, python.
17. Write a recursive function to print all consecutive substrings of
    length 3. Example: codegnan -> cod, ode, deg, egn, gna, nan.
18. Write a recursive function to find the product of all elements in a
    list.
19. Write a recursive function to check whether a number is prime.
20. Write a recursive function to find the Greatest Common Divisor (GCD)
    of two numbers.

LEVEL 3: ADVANCED (21-30) Focus: Complex recursion, multiple recursive
calls, backtracking, and problem-solving.

21. Write a recursive function to generate the Fibonacci series up to N
    terms.
22. Write a recursive function to find the second-largest element in a
    list.
23. Write a recursive function to check whether a list is sorted in
    ascending order.
24. Write a recursive function to remove all occurrences of a given
    element from a list.
25. Write a recursive function to count the frequency of each element in
    a list.
26. Write a recursive function to convert a decimal number into binary.
27. Write a recursive function to find all permutations of a given
    string.
28. Write a recursive function to generate all subsets of a given list.
29. Write a recursive function to solve the Tower of Hanoi problem.
30. Write a recursive function to solve the N-Queens problem.
